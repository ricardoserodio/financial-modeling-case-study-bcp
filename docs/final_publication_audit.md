## 2. Forecast Horizon Decision

The project will retain a three-year illustrative forecast horizon:

- 2026E
- 2027E
- 2028E

This is intentional.

The forecast horizon is used to demonstrate:

- multi-year banking forecast logic;
- scenario modelling;
- financial statement drivers;
- banking ratio analysis;
- Power BI scenario visualisation;
- data quality and review controls.

Forecast outputs must remain clearly labelled as:

- illustrative;
- scenario-based;
- simplified;
- human-reviewed;
- not official projections;
- not investment advice;
- not suitable for investment decisions.

## 3. Scenario Framework

The project uses three scenarios:

| Scenario | Purpose |
|---|---|
| Base | Central illustrative case based on simplified assumptions. |
| Optimistic | Upside illustrative case with stronger income, efficiency, risk and capital assumptions. |
| Conservative | Downside illustrative case with weaker income, higher cost pressure and higher risk assumptions. |

The scenarios are not predictions.

This project should be presented as:

> A public banking analytics and financial modelling case study combining banking experience, financial data quality, scenario analysis, Power BI reporting and a human-reviewed AI-assisted workflow.

It should not be presented as:

> An investment recommendation, stock valuation call, trading model or performance prediction.

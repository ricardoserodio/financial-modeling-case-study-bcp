# Current forecast methodology

The current model is the [29 September revision](../revisions/2026-09-29/METHODOLOGY.md). Its self-contained inputs and outputs live under `revisions/2026-09-29`.

It uses a 48% illustrative conversion reference with sensitivities, separates retention from operating scenarios and does not forecast CET1 or reported-basis ROE/ROA. Use [current run instructions](../RUN_PROJECT.md).

The [previous v5 methodology](archive/forecast_methodology_v5_2026-09-28.md) is retained for historical reproduction. Root-level legacy scenario CSVs and the original PBIX forecast page use that earlier model.

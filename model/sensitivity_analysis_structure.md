# Sensitivity Analysis Structure

This file documents the intended structure of the sensitivity analysis for the **Millennium bcp / Banco Comercial Português** financial modeling case study.

The sensitivity analysis will be created in:

`model/sensitivity_analysis.xlsx`

This analysis is for educational and portfolio purposes only and does not constitute investment advice.

---

## Purpose

The purpose of the sensitivity analysis is to test how changes in key assumptions affect the model outputs and illustrative valuation results.

The analysis helps reduce overconfidence in a single forecast or valuation output by showing a range of possible outcomes.

---

## Key Sensitivity Variables

The sensitivity analysis may include the following variables:

| Variable | Reason for Sensitivity |
|---|---|
| ROE | Key profitability and valuation driver for banks |
| Cost of equity | Important input in equity valuation logic |
| Earnings growth | Affects earnings-based valuation |
| Net interest income growth | Key revenue driver for banks |
| Fees and commissions growth | Important non-interest income driver |
| Cost-to-income ratio | Measures operating efficiency |
| Cost of risk | Affects impairments and net income |
| Loan growth | Affects balance sheet and income generation |
| Deposit growth | Affects funding structure |
| P/B multiple | Direct impact on book-value-based valuation |
| P/E multiple | Direct impact on earnings-based valuation |
| Dividend payout | Affects capital return and retained earnings |

## Scenario Link

The sensitivity analysis should connect with the three model scenarios:

| Scenario | Sensitivity Use |
|---|---|
| Conservative | Lower profitability, weaker efficiency or higher risk assumptions |
| Base | Balanced assumptions based on historical performance and public information |
| Optimistic | Stronger profitability, better efficiency or lower risk assumptions |

The sensitivity analysis should not suggest that any scenario is guaranteed.

---

## Output Guidelines

Sensitivity outputs should be presented as ranges.

The analysis should avoid:

- single-point certainty;
- investment recommendation language;
- target price language;
- unsupported upside or downside claims;
- excessive precision.

Preferred language:

- illustrative range;
- sensitivity-based outcome;
- scenario-dependent result;
- educational valuation exercise;
- subject to limitations;
- not investment advice.

---

## Data Quality Checks

Before finalising the sensitivity analysis, check:

- Are all inputs linked to documented assumptions?
- Are actual and forecast figures clearly separated?
- Are formulas consistent across the tables?
- Are percentage inputs formatted correctly?
- Are valuation multiples shown as `x` and not as percentages?
- Are outputs reviewed against the model review checklist?
- Is the language free from investment recommendation wording?

---

## Limitations

The sensitivity analysis has several limitations:

- It is simplified and educational.
- It does not represent a professional valuation model.
- It does not produce an official target price.
- It relies on simplified assumptions.
- It does not include all macroeconomic, regulatory or market variables.
- It does not use internal or confidential information.
- It is based only on public-source data and illustrative assumptions.
